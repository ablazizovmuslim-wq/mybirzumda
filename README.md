# Birzumda — mybirzumda.uz

Сайт бренда Birzumda: все проекты (Telegram-боты) в одном месте.

| Файл | Что делает |
|---|---|
| `index.html` + `script.js` | главная: проекты, отзывы, о нас, FAQ |
| `cabinet.html` + `cabinet.js` | личный кабинет: заказы, бонус, рефералы, промокод |
| `admin.html` + `admin.js` | админ-панель (только ADMIN_ID) |
| `core.js` | общий код: настройки, запросы к API, вход/выход |
| `style.css` | дизайн: темы, цвета, стекло, анимации |
| `CNAME` | домен для GitHub Pages |

API сайта находится в боте Birzumda Tayyorla (`site_api.py`, пути `/api/site/...`).
